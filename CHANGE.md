# Change Log

## v1.1.0 - 2026-06-23

### Added
- Added the Braun theme styling and theme toggle.
- Added macOS close-window behavior that keeps the app running in the background.
- Added Dock reopen handling so the hidden main window is shown again when reopening the app.

### Changed
- Updated release version metadata to `1.1.0` across npm, Cargo, and Tauri config.
- Documented the release/versioning checklist in `AGENTS.md`.
